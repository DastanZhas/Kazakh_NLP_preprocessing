Basic Kazakh NLP preprocessing using Harvard Stanza Toolkit (https://ui.adsabs.harvard.edu/abs/2020arXiv200307082Q/abstract) - Stanza: A Python Natural Language Processing Toolkit for Many Human Languages [https://doi.org/10.48550/arXiv.2003.07082]

Since most of the NLP toolkits does not support the Kazakh language, only few toolkits support the preprocessing of the Kazakh language texts.

Processing includes:
 - Tokenization
 - Cleaning from stop words
 - Lemmatizing
 - Vectorizing

This pipeline was written and tested in early 2023, so some statements above might be outdated.
